# Reglas para agentes IA

Antes de escribir código:

- Leer AI_CONTEXT.md
- Analizar archivos relacionados
- Explicar el plan

Prohibido:

- crear archivos duplicados
- crear componentes alternativos
- reemplazar arquitectura existente
- cambiar Prisma sin autorización
- cambiar NextAuth sin autorización

Siempre:

- modificar lo mínimo posible
- mantener compatibilidad multi-tenant
- mantener TypeScript estricto
